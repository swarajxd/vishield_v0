# ViShield starter dataset

`starter_dataset.jsonl` contains **80 fictional transcripts** (8 per category, 10 categories)
written by the project team for the academic prototype. Every organisation, officer, phone
number and website is a placeholder (Example Bank, Sample Delivery, Demo Telecom, Placeholder
Software, Fictional City Cyber Cell). No real people, numbers, emails or URLs appear.

| Category | Label | Count |

Binary balance is 56 phishing : 24 legitimate. The classifier uses `class_weight="balanced"`
and stratified splits to compensate. See `docs/DATASET_CARD.md` for the full card.

## Files

- `schema.json` – JSON Schema (draft-07) for each record.
- `starter_dataset.jsonl` – the records.
- `splits/{train,val,test}.jsonl` – generated by `python scripts/split_dataset.py` (seed 42).
- `splits/report.json` – class-distribution report written by the split script.

## Adding consented samples

1. Obtain **written consent from every speaker** and keep the consent record outside the repo.
2. Transcribe locally. Do **not** commit audio.
3. Run the transcript through the redactor: `python scripts/redact_text.py "<text>"` and check
   the output manually for names, addresses or identifiers.
4. Append a record with `source: "consented"`, a `license` string, and `consent` set to an
   opaque reference such as `consent-form-2026-014` (never a person's name).
5. Run `python scripts/validate_dataset.py` – it rejects duplicates, PII-like patterns and
   schema violations.
6. Re-run `python scripts/split_dataset.py` and `python scripts/train_model.py`.
7. Open a pull request; a second team member must review the sample for privacy.
